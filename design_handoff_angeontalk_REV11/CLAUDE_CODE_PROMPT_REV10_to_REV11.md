## 👇 여기서부터 Claude Code에 붙여넣기

안건톡(건설 현장 업무 메신저) 기존 구현(REV10)에 REV11 변경분을 추가해줘.
REV11은 회원가입 흐름 중 역할·현장·공종 선택 이후에 빠져 있던 **"본인 정보 입력" 단계**를 새로 추가하는 작업이다.
REV11 디자인 레퍼런스: `design_handoff_angeontalk_REV11/anrgeontalk_wireframes_rev11.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 `<style>`에 인라인, 화면 하단 `<script>`에 순수 JS 인터랙션). 온보딩은 문서 최상단의 **단일 인터랙티브 프로토타입 디바이스**로, `.ob-step[data-step]` 단계 전환식이다.

기존 다크 테마, Pretendard 폰트, "상태 배지에만 색을 쓰는" 원칙, 큰 터치 타깃, 한글 UI를 유지하고, REV10까지 확정된 화면·레이아웃·색상·플로우는 건드리지 말 것. 브랜드 액센트(옐로우) #ffd60a는 CTA·포커스 한정.

**REV11은 화면 흐름·입력·로컬 상태 전환까지 구현한다.** 서버 저장·실제 인증 로직은 이번 범위에 포함하지 않는다.

### 배치 위치 (흐름 변경)
"본인 정보 입력"(`data-step="profile"`)은 각 역할별 흐름의 **마지막 단계**, 즉 승인 요청을 보내거나 즉시 가입이 완료되기 **직전**에 들어간다.
- 발주처·한미글로벌: 현장 선택(`site`) → **profile** → 가입 완료(`done`)
- 시공사: 공종 선택(`trade`) → 업체명(`cCompany`) → **profile** → 다이얼로그 → 승인대기(`wait`)
- 협력사: 원청 선택(`origin`) → 공정·업체명(`pCompany`) → **profile** → 다이얼로그 → 승인대기(`wait`)

즉 REV10에서 `cCompany`·`pCompany`의 "승인 요청 보내기" 버튼은 **"다음"으로 바뀌어 `profile`로 이동**하고(이때 업체명/공정을 `reg`에 캡처), 승인 요청 발송·가입 완료 분기는 `profile`의 하단 버튼으로 옮겨진다. `site` 클릭 시 발주처·한미글로벌 분기는 `done`이 아니라 `profile`로 간다.

### REV11 변경 요약 (신규 화면 1개 · `data-step="profile"`)
- 상단 "본인 정보를 입력해주세요" + 지금까지 선택한 **역할·현장·공종(또는 공정)** 요약 카드(`.ob-summary.tight`). 발주처·한미글로벌은 공종 행 숨김.
- **필수 항목**: 성명 / 직급 / 휴대전화 번호. **발주처·한미글로벌일 때만 소속 부서 필드 추가**(시공사·협력사는 업체명을 이미 입력했으므로 부서 없음).
- **소속 부서는 자동완성**: 입력값을 포함하는 후보를 그 아래 드롭다운(`.ob-ac-list`, 기존 검색 인풋 톤 재사용)으로 표시, 탭하면 필드에 채움. 목업 키워드: 공무→[공무부, 공무팀, 공무, 공무부서], 품질→[품질부, 품질팀, 품질관리팀, 품질경영팀], 안전→[안전관리부, 안전팀, 안전보건팀, 안전환경팀], 공사→[공사부, 공사팀, 공사관리팀, 공무공사팀].
- 구분선(`.ob-optdiv`) 아래 **"선택 입력"** 소제목. 선택 항목: **입사년도**(연도 드롭다운 `<select>`, 2026~1990)와 **전문분야**(다중 선택 칩 `.ob-chips`: 구조·공정관리·품질·안전·원가·설계). 라벨 옆 흐린 톤 `(선택)`(`.ob-opt`).
- 하단 큰 버튼(`#ob-prof-submit`): 발주처·한미글로벌이면 "가입 완료" → `done`; 시공사·협력사면 "승인 요청 보내기" → 확인 다이얼로그 → `wait`.
- **필수 항목이 비어 있으면 하단 버튼 비활성**(`disabled`). 필수 인풋에 `[data-pf-req]` + `input` 리스너로 `validateProfile()` 재검사.

### 데이터 / 상태 모델 (REV11 추가분)
- **UserRegistration**에 `name`, `title`, `phone`, `dept`(발주처·한미글로벌만) 필드 추가. `reg.status`는 profile 하단 버튼에서 확정(발주처·한미글로벌 `active`, 시공사·협력사 `pending`).
- `reset()`에 profile 인풋·연도·전문분야 칩·부서 드롭다운 초기화 추가.

### 구현 지침
- REV10 코드 구조/컴포넌트 패턴/상태관리/디자인 토큰 소스를 그대로 따라 신규 화면·상태 추가.
- 자동완성 드롭다운은 기존 검색 인풋 스타일(REV5)의 시각적 톤을 재사용.
- 요약·부서 필드 노출·버튼 라벨은 `onEnter('profile')` 진입 시점에 `reg`에서 주입.
- 변경 후 REV10 화면 회귀가 없는지 확인.
