# Handoff: 안건톡 (AngeonTalk) — 건설 현장 업무 메신저

## Overview
안건톡은 카카오톡·라인과 **동일한 사용성**의 일반 업무 메신저다. 방 생성/폐기, 사진·파일 전송, 1:1·그룹 채팅이 모두 가능하다. 여기에 **단 하나의 기능**이 추가된다: 대화 중 "안건(Agenda)"을 생성하면 그 문제 전용 **서브 채팅방**이 만들어지고, 링크 카드가 원래 방의 대화 스트림에 게시된다. 안건방에서는 AI가 대화를 요약하고, 완료 시 기술사례(지식자산)로 자동 축적하며, 6개월 후 자동 추적한다.

핵심 설계 원칙:
1. 현장 직원의 **학습비용 0** — 기존 메신저 UI 문법을 그대로 따른다.
2. 사용자 입력 최소화 — AI가 초안을 만들고 사용자는 확인/승인만 한다.
3. 안건은 별도 메뉴 체계가 아니라 **대화 속 카드**로 존재한다.
4. 모바일 우선. 하단 탭은 2개(채팅 / 마이페이지)로 제한.

## About the Design Files
이 번들의 `anrgeontalk_wireframes.html`은 **HTML로 만든 디자인 레퍼런스**다 — 의도한 외관과 동작을 보여주는 프로토타입이지, 그대로 복사해 배포할 프로덕션 코드가 아니다. 파일은 하나의 문서 안에 모든 화면을 아이폰 프레임(390×844)으로 나란히 배치한 형태다.

과제는 이 HTML 디자인을 **타깃 코드베이스의 기존 환경**(React Native / Flutter / SwiftUI / Kotlin 등)에서, 그 환경의 확립된 패턴과 라이브러리를 사용해 **재구현**하는 것이다. 환경이 아직 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현한다. 메신저 앱이므로 **React Native 또는 Flutter** 같은 크로스플랫폼 모바일 프레임워크를 권장한다.

## Fidelity
**중간 충실도 (mid-fi) 와이어프레임.** 레이아웃·정보구조·플로우·색상 체계·컴포넌트 구성은 확정 수준이지만, 픽셀 퍼펙트 최종 시안은 아니다. 다크 테마, 상태 색상 체계, 큰 터치 타깃(장갑 착용 대응), 한글 UI는 그대로 따르되, 세부 여백·폰트 렌더링·아이콘 세트는 타깃 플랫폼의 디자인 시스템에 맞춰 조정할 것. 사진/도면은 스트라이프 플레이스홀더로 표현돼 있다 — 실제 이미지·도면 뷰어로 대체한다.

### Typography
- Font family: **Pretendard** (한글 UI 표준). Fallback: `system-ui, sans-serif`.
- 안건번호(`#153` 등)와 안건방 헤더 타이틀은 `ui-monospace` 계열(라벨 느낌).
- 스케일(px): 타이틀 20/19/18/17 · 본문·말풍선 15~16 · 리스트 제목 15~16 · 보조 13~14 · 캡션/시각 11~12.
- Weight: 기본 600, 강조 700, 헤더/CTA 800.

### Spacing / Radius
- 카드 radius 16, 시트 상단 radius 24, 버튼/입력 radius 12~14, 배지 pill 999.
- 말풍선: 받은 `4 16 16 16`, 보낸 `16 4 16 16` (꼬리 방향).
- 화면 좌우 패딩 14~16, 카드 내부 패딩 12~16.

### Touch targets (중요 — 장갑 착용 대응)
- 아이콘 버튼 44×44 최소.
- [+]/전송 버튼 48×48, 입력 필드 높이 48.
- 주요 CTA(안건 게시/완료 처리/질문 올리기) 높이 52~56.
- 큰 토글·우선판단 버튼 54~76 높이.

### Device frame
- 디자인 기준: iPhone 390×844 논리 픽셀. 상단 노치, 상태바 높이 52, 하단 탭바 76(safe-area 14 포함).

## Screens / Views

> 각 화면은 HTML에서 `<!-- SCREEN n -->` 주석과 `.frame-label`로 식별된다.

### 화면 1 — 홈 · 채팅방 목록 (SCREEN 1)
- **목적**: 카카오톡 채팅 탭과 동일한 방 목록. 앱 진입점.
- **레이아웃**: 상단 앱바("채팅" 타이틀 + 검색/설정 아이콘) → 검색바 → 방 리스트(세로 스크롤) → 하단 탭바 2개.
- **방 항목(`.room`, min-height 76)**: 좌측 52×52 라운드 아바타(공종 아이콘 + 인원수 뱃지) / 방 이름 / 마지막 메시지 미리보기(1줄 말줄임) / 우측 상단 시각 + 안읽음 배지.
- **공종방 전용**: 미리보기 아래 "진행중 안건 N건" **서브 배지**(주황 pill, `.agenda-sub`). 일반방·1:1엔 없음.
- **방 종류(더미)**: 건축방(안건3·안읽음5), 토목방(안건1·2), 설비방(안건2), 전기방, 협력사 단톡방(안읽음12), 김공무 과장(1:1).
- **탭바**: 채팅(활성) / 마이페이지. 2개만.

### 화면 2 — 공종방(건축방) + [+] 메뉴 (SCREEN 2)
- **목적**: 일반 채팅방. 텍스트·사진·파일 자유 전송 + 대화 중 안건 카드.
- **헤더**: 뒤로가기 + "건축방" + 인원수(24) + 우측 검색·햄버거(≡).
- **대화 스트림**: 받은 텍스트, 사진(플레이스홀더), 보낸 텍스트, 파일 카드(pdf, 1.8MB), **안건 카드**, 받은 텍스트.
- **안건 카드(`.agenda-card`, max 320)**: 헤더(안건 #153 + 상태배지 검토중) / 제목 / 메타행(🌙 야간 등록 + "3일째 진행중" 숙성 배지) / 사진 썸네일 / 푸터(참여자 5명 + "탭하여 안건방 이동" 주황 힌트).
  - **숙성 배지 2종**: `age-neutral`(활발한 장기안건=중립색) / `age-warn`(방치=경고 주황). 야간/주말 외 등록엔 🌙 미표시.
- **입력바**: 좌측 [+](활성 시 45° 회전 + 옐로우) + 입력필드 + 전송.
- **[+] 메뉴(`.plusmenu`, 4열 그리드)**: 사진 / 카메라 / 파일 / **안건 올리기(강조 — 옐로우 배경)** / 질문하기.

### 화면 3 — 안건 올리기(등록) (SCREEN 3)
- **목적**: "입력이 거의 없다"는 느낌의 안건 등록. AI가 칩을 자동 추론.
- **헤더**: 좌측 닫기(X) + "안건 올리기" + 우측 **비활성** "게시" 버튼.
- **사진 영역(지배적, 점선 테두리 빈 상태)**: 카메라 아이콘 + "사진 촬영 또는 선택". 사진 넣으면 썸네일 그리드로 전환.
- **한 줄 입력**: placeholder "간단한 문제 설명 (선택)" — (선택) 명시.
- **자동 채운 칩 3개(회색톤·수정 가능 느낌)**: 📍 A동 3층 / 🔨 철근공사 / 👤 담당자 지정.
- **"도면에서 위치 지정" 버튼**(아이콘+텍스트).
- **하단 큰 "안건 게시" 버튼**.

### 화면 3-1 — 도면 위 위치 핀 (SCREEN 3-1)
- **목적**: 지도 앱처럼 도면 위를 탭해 핀을 찍는다.
- **상단 도면 정보 바**: "A동 3층 평면도 · Rev.04 (최신 승인)" — **리비전 표시가 중요**.
- **본문**: 클라우드에서 자동 로드된 평면도가 화면 대부분 차지. 이미 꽂힌 핀 1개 + 탭 가능한 고스트 핀.
- **하단 "이 위치로 지정" 버튼**.

### 화면 4 — 안건방(서브 채팅방) (SCREEN 4)
> **이 제품의 핵심 화면.** 일반 채팅방과 똑같이 생겼지만 3가지가 추가된다.
- **헤더**: 뒤로가기 + "안건 #153" + 상태배지(검토중, 탭하면 변경 — 셰브론↓). 아래 작은 제목 "A동 3층 슬래브 철근 피복두께 검토".
- **① AI 요약 카드(`.aisum`, 상단 고정/핀, 접기·펼치기)**: 📌 "AI 요약" 레이블 / 본문("스페이서 누락으로 피복두께 부족 가능성 제기. 재배근 결정, 재검측 대기중.") / 미결사항 2줄(불릿) / **근거 출처 줄**("📎 유사사례 12건 · 사내 품질기준 3.2조 기반" — 흐린 톤, 탭하면 근거 목록 펼침). 배경을 대화와 다르게.
- **② 도면 리비전 배너(`.revbanner`)**: "⚠️ 검토하신 부위의 도면이 개정되었습니다 Rev.04 → Rev.05" + 우측 "변경 확인" 버튼 + 우상단 닫기(X). 주황 옅은 배경(과하지 않게).
- **③ 대화 스트림**: 김대리 질문 → 사진 → 품질팀 → **현장소장 메시지(좌측 강조 보더 + 하단 "📌 결정근거" 라벨)** → 김대리 보낸 메시지("재배근 완료했습니다").
- **하단 액션 칩 바(가로 스크롤, 입력창 위)**: 상태변경 / 담당자 / 유사사례 / **보고서 작성(강조색)** / 완료처리.
- **최하단**: 일반 채팅 입력창([+] + 필드 + 전송).

### 화면 4-1 — 메시지 롱프레스 컨텍스트 메뉴 (SCREEN 4-1)

- **헤더**: 뒤로가기 + "건축방 · 안건 리스트" + 우상단 도면 다중핀 뷰 전환 아이콘.
- **카운터 3개(가로)**: 진행중 12(파랑) / 완료 47(녹색) / 이번 주 신규 5.

- **항목(`.agitem`)**: 썸네일 + 안건번호 + 제목 + 최근 업데이트 시각 + 우측 상태배지. **3일 이상 무응답 안건은 좌측 주황 경고 마커(`.stale`) + "3일간 응답 없음"**.

### 화면 6 — 보고서 형식 선택 시트 (SCREEN 6)

- **선택지 3개**(아이콘+제목+한줄): 진행상황 중간보고 / 조치완료 보고서(사내 정식) / 발주처·감리 제출용 공문(공문 서식 자동 변환).

### 화면 7 — 기술사례 자동 생성 카드 (SCREEN 7)
- **진입**: 안건 "완료처리" 시 안건방에 게시.
- **헤더**: "✅ 기술사례 초안이 생성되었습니다" + 사례번호 CASE-2026-0153.
- **접힌 항목(탭하면 펼침, 1줄 요약)**: 문제 / 원인 / 검토 대안 / 최종 결정 / 결정 근거 / 조치 결과 / 재발방지.
- **하단 버튼 3개**: 승인(녹색) / 수정 / 반려(빨강 텍스트).

### 화면 8 — 완료 처리 시트 (SCREEN 8) 【핵심 데이터 수집 지점】
- **원칙**: 10초 내 완료, 서술형 입력 없음(전부 탭), "귀찮은 설문"이 아닌 "마무리 확인", 3단계 세로 스크롤(스텝 이동 없음).
- **상단**: "안건을 완료 처리합니다" + 제목 한 줄.
- **1단계 조치 이력(자동, 입력 없음)**: "재조치 2회 발생" + 녹색 **"사례 가치 높음" 배지(💎)** — 재조치를 실패가 아닌 가치로 프레이밍. 재조치 없으면 "1회 조치로 완료" 담백 표시.
- **2단계 이견 여부**: "검토 과정에서 전문가 간 이견이 있었나요?" + [있었음]/[없었음] 큰 토글. "있었음" 선택 시 참여자 목록 펼침(체크 선택, 건너뛰기 가능) + 안내 "이견 기록은 판단 기준을 후배에게 전달하는 자료가 됩니다".
- **3단계 우선 판단**: "이 결정에서 우선한 것은?" + 공기/원가/품질/안전 2×2 아이콘 그리드, **최대 2개 복수선택**(강조 테두리) + "최대 2개 선택" 안내.
- **하단 큰 "완료 처리" 버튼**: 2·3단계 건너뛰어도 완료 가능(강제 X). 건너뛰면 버튼 위 "일부 항목이 비어 있습니다" 안내.

### 화면 11 — 착공 전 사전검토 안건 (SCREEN 11)
- **사전검토 카드**: 상태배지 자리에 **보라 "사전검토" 배지**. 사진 대신 도면 썸네일 + 핀. 하단 예측정보 "착공 전 등록 · D-92".
- **문제 적중 카드**: 상단 연결 배너 "🎯 3개월 전 사전검토와 일치하는 문제가 발생했습니다"(보라→녹색 그라데이션) + "사전검토 안건 #128 보기" 링크 + 일반 안건 카드(#167). **베테랑 예측 적중의 성취감**을 주도록 디자인.

### 화면 12 / 12-1 — 6개월 후 추적 (SCREEN 12, 12-1)
- **12 푸시 알림(잠금화면)**: 큰 시각/날짜 + 알림 카드 "[안건 #153] 6개월이 지났습니다. A동 3층 슬래브 부위, 이상 없으신가요?"
- **12-1 응답 화면**: 상단 당시 요약 카드(문제·조치·결과 3줄 + 당시 사진) → 도면 핀 미니맵 → "해당 부위에 현재 이상이 있습니까?" → 버튼 3개 [이상 없음]/[재발 확인됨 → 새 안건 등록]/[확인 어려움] → 하단 안내 "응답 결과는 이 사례의 신뢰등급에 반영됩니다". **"재발 확인됨" → 새 안건 등록 플로우로 연결**.

## Interactions & Behavior
- **안건 생성**: 공종방 [+] → "안건 올리기" → 화면3(사진+AI칩) → (선택)화면3-1 도면 핀 → "안건 게시" → 원래 방 스트림에 안건 카드 게시 + 안건방(서브채팅) 생성.
- **안건 카드 탭** → 안건방(화면4) 진입. 뒤로가기로 공종방 복귀.
- **상태 배지 탭**(안건방 헤더) → 상태 변경(검토중↔조치중↔완료).
- **AI 요약 카드**: 접기/펼치기, 근거 출처 줄 탭 시 근거 목록 확장.
- **리비전 배너**: "변경 확인" 탭 시 개정 도면 diff/확인, X로 닫기.
- **메시지 롱프레스** → 컨텍스트 메뉴(답장/복사/📌결정근거 태그/삭제).
- **결정근거 태그**: 태그된 메시지는 좌측 강조 보더 + "📌 결정근거" 라벨. AI 요약/기술사례의 "결정 근거" 소스가 됨.
- **보고서 작성 칩** → 바텀시트(화면6) 슬라이드 업.
- **완료처리 칩** → 완료 시트(화면8) → "완료 처리" → 기술사례 카드(화면7) 생성.
- **기술사례 승인/수정/반려** → 지식자산 확정/편집/폐기.
- **6개월 자동 추적**: 완료 안건에 대해 6개월 뒤 푸시(화면12) → 응답(화면12-1). "재발 확인됨" → 새 안건 등록.
- **애니메이션**: 바텀시트 slide-up + scrim 페이드, [+] 버튼 45° 회전 전환, 컨텍스트 메뉴 팝.
