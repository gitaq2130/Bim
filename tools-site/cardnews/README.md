# 카드뉴스 생성기

계산기 하나당 카드 3장을 자동으로 만든다. 디자인 작업이 없다.

```bash
node export_cards.mjs     # 문구 → cards.json
python3 render_cards.py   # → out/<slug>/1.png 2.png 3.png
```

의존성: `Pillow`, `fonttools`(글리프 검사용, 없으면 검사만 건너뜀).

## 왜 이걸 만드나

카드뉴스나 쇼츠 자체로는 돈이 되지 않는다. 인스타는 직접 광고 수익이 사실상
없고, 유튜브 쇼츠는 90일간 1,000만 조회를 요구한다.

**그러니 이건 수익원이 아니라 유입 장치로 쓴다.** 계산기는 만들어 뒀지만
아무도 모르면 수익이 0이다. 카드뉴스는 검색으로 들어오지 않는 사람을
계산기까지 데려오는 역할만 하면 되고, 그 목적에는 조회수 1,000만이 필요 없다.

## 카드 3장 구성

| | 내용 | 왜 |
|---|---|---|
| 1 | 후킹 | "어 나도 그런데" 하는 지점. 어두운 배경으로 눈에 띄게 |
| 2 | 핵심 | 몰랐으면 틀렸을 사실 하나 |
| 3 | 예시 | 숫자로 보여주고 계산기로 유도 |

1080×1350(인스타 세로) 규격이다.

## 문구 고치기

`cards.config.mjs` 만 고친다. 도구 코드(`../src/tools/`)와 분리해 두었다 —
저쪽은 제품이고 이쪽은 홍보 문구라 고치는 이유와 주기가 다르다.

## 글꼴에 없는 글자 주의

Pretendard 에 없는 글자를 쓰면 **검은 블록으로 렌더된다.** 이미지라서 파일을
열어보기 전까지 드러나지 않는다. 실제로 이런 것들이 걸렸다.

| 글자 | 상태 | 대체 |
|---|---|---|
| `✕` U+2715 | 없음 | `×` U+00D7 |
| `金` `整` | 없음 | 한글로 "일금 … 원정" |
| `×` `○` `△` `→` `㎡` | 있음 | 그대로 사용 |

`render_cards.py` 가 렌더 전에 자동으로 검사하고, 없는 글자가 있으면
어느 카드의 어느 항목인지 알려주며 중단한다.

## 운영

**한 주에 한 세트씩만 올려도 11주 분량이다.** 계산기를 추가하면
`cards.config.mjs` 에 항목을 하나 더해 다시 돌리면 된다.

게시할 때는 계산기 주소를 프로필 링크나 첫 댓글에 둔다.
카드에서 바로 링크를 걸 수 없는 플랫폼이 많다.
