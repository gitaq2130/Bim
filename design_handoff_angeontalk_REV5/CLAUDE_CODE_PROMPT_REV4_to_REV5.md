## 👇 여기서부터 Claude Code에 붙여넣기

안건톡(건설 현장 업무 메신저) 기존 구현(REV4)에 REV5 변경분을 반영해줘.
REV5 디자인 레퍼런스: `design_handoff_angeontalk_REV5/anrgeontalk_wireframes_rev5.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 상단 `<style>`에 인라인, 각 화면은 `<!-- SCREEN n -->` 주석으로 구획).

REV5의 핵심은 **검색 3곳에 실제 필터링 로직 구현**이다. REV4까지는 검색 입력창이 스텁(입력해도 리스트가 반응하지 않음)이었는데, REV5에서 실동작으로 만든다. 다크 테마·Pretendard·"상태 배지에만 색" 원칙·큰 터치 타깃·한글 UI·기존 레이아웃은 모두 유지하고, 아래 검색 기능만 추가·수정해줘.

### REV5 변경 요약

**공통 규칙**
- 입력 멈춘 후 **200~300ms 디바운스** 적용(매 타이핑마다 재계산 금지).
- 매칭은 **소문자 정규화 후 부분 일치**(대소문자·자모 단위 구분 없음).
- 결과 0건일 때 **"검색 결과가 없습니다"** 빈 상태 문구 노출.

**[1] 홈(채팅) 화면 — 헤더 토글형 검색**
- 헤더 우측에 🔍 돋보기 아이콘(⚙️ 설정 아이콘 **왼쪽**에 배치).
- 기본 상태에서는 검색창이 전혀 보이지 않고, 채팅방 리스트가 헤더 바로 아래부터 시작.
- 🔍 탭 시 헤더 아래로 **슬라이드다운** 검색 입력창 등장. placeholder `"채팅방 검색"`.
- 입력창 우측 **취소(X)** 버튼 → 탭하면 슬라이드업으로 사라지고 기본 상태 복귀(입력값 초기화).
- 실시간 필터: 입력값이 **방 이름** 또는 **최근 메시지 내용**에 포함되면 매칭, 나머지는 숨김. 비면 전체 복귀.

**[2] 연락처 탭 — 헤더 토글형 검색**
- 헤더 🔍 탭 시 검색창 노출.
- 입력값이 **이름·직급·소속 회사** 중 하나에 포함되면 매칭.
- 공종별 그룹 구조 유지하되, 매칭 안 되는 항목/그룹 숨김. **그룹 내 전원이 필터링되면 그 그룹 헤더도 함께 숨김.**

**[3] 공종방(채팅방) 내부 — 헤더 토글형 검색**
- 헤더 🔍 탭 시 검색바 노출(입력창 + 결과 카운트 + 위/아래 이동 화살표).
- 입력값이 해당 방의 **메시지 텍스트**에 포함되면 매칭.
- 매칭된 메시지로 **스크롤 이동 + 하이라이트**. 매칭이 여러 개면 위/아래 화살표로 다음/이전 결과 탐색(`현재/전체` 카운트 표시).

### 구현 지침
- 세 검색 모두 **클라이언트 사이드 필터**로 충분(현재 목 데이터 기준). 실제 구현 시 방 목록·연락처·메시지 각각의 상태(state)에서 파생 필터로 구현할 것.
- 레퍼런스 HTML은 대표 화면(홈=화면1, 건축방=화면2, 연락처=화면14)에만 JS를 연결해 뒀다. 실제 앱에서는 동일 로직을 각 리스트/방 컴포넌트에 재사용.
- 스크롤 이동은 `scrollIntoView` 대신 컨테이너 `scrollTo` + 대상 `offsetTop` 계산 방식으로(레퍼런스와 동일).
- UI·레이아웃·색상·플로우는 REV4와 동일. 검색 외 회귀(변경) 없어야 함.
