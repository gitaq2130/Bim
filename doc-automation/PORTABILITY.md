# 스킬 이식성 감사

문서 자동화 스킬 5종이 **다른 현장에서도 도는가**를 항목별로 실사한 결과다.
Tier 1(도구 판매)로 넘어가려면 스킬이 특정 현장에 묶여 있으면 안 된다.

이 문서는 두 가지로 쓴다.
1. 어떤 스킬을 **먼저 팔지** 정하는 근거 — 이식 공수가 낮은 것부터 판다.
2. **초기 세팅 견적**의 근거 — "왜 300만원인지"를 공수로 설명할 수 있어야 한다.

판정 기준은 하나다. **"현장 이름만 바꾸면 도는가, 아니면 로직을 고쳐야 하는가."**

---

## 요약

| 스킬 | 현장 종속성 | 이식 공수 | 판매 순서 |
|---|---|---|---|
| 회의록 | **거의 없음** | 0.5일 | **1순위 — 지금 바로** |
| 하도급계약 검토·확인서 | 머리말·서명란만 | 2일 | 2순위 |
| 문서관리대장 누락 대조 | 문서번호 체계·대장 서식 | 2일 | 3순위 |
| 주간 회의안내 메일 | 수신자·일정 | 1일 | 묶어서 제공 |
| 휴일작업계획서 취합 | **서식 전체** | 5일+ | 마지막 · 별도 견적 |

**결론: 회의록부터 판다.** 이식 공수가 사실상 0이라 첫 고객에게 오늘 보낼 수 있고,
현장에서 가장 자주 발생하는 문서라 절감 효과도 가장 먼저 체감된다.

---

## 1. 회의록 — 이식 공수 0.5일

**현장 종속 값**: 파일명 규칙의 예시 약칭 하나뿐.

산출물 규격(`No. | 안건 | 핵심 내용 | 결론 및 조치사항` 4열 표, 발주처 지시사항 빨강 볼드)은
특정 현장의 서식이 아니라 **발주처–PM단 회의록의 일반형**이다. 안건 추출·요약 규칙,
금액 증감 부호(`+6,300만원` / `△3,700만원`), STT 오인식 교정 절차 모두 현장과 무관하다.

> 이 스킬은 **이미 제품이다.** 프로파일의 `project.shortName`만 읽게 바꾸면 끝난다.

**해야 할 일**: 파일명 규칙을 `{YYMMDD}_{project.shortName}_{회의명}.docx` 로 바꾼다.

---

## 2. 하도급계약 검토·확인서 — 이식 공수 2일

**현장 종속 값** (전부 머리말·서명란, 로직 아님):

| 항목 | 현재 | 프로파일 키 |
|---|---|---|
| 공사명 | 하드코딩 | `project.name` |
| 원사업자 / 대표자 | 하드코딩 | `primeContractor.name` / `.representative` |
| 원도급 공사기간 | 하드코딩 | `project.period` |
| 건설사업관리기술자 | 하드코딩(실명) | `cm.engineer` |

**로직은 전부 범용이다.** 14개 검토항목의 근거법령·표준 문구, 그리고 11번 건설기술자 배치기준
자동 산정은 **건설산업기본법 시행령 제35조제2항 별표5**를 그대로 구현한 것이라
어느 현장에서나 동일하게 성립한다. 이게 이 스킬의 판매 가치다 —
사람이 매번 법령 표를 다시 들여다볼 필요가 없다.

### ⚠ 배치기준 표가 틀렸다 — 우선 수정 대상

현재 스킬의 11번 자동 산정 표는 **별표5 원문과 다르다.** 원문을 두 독립 출처로
대조한 결과 전 구간이 한 등급씩 낮게 잡혀 있다.

| 공사예정금액 | 스킬의 현재 값 | 별표5 원문 |
|---|---|---|
| 700억 이상 | 기술사 | 기술사 |
| 500억 이상 | 특급기술자 이상 | **기술사 또는 기능장** |
| 300억 이상 | 특급기술자 이상 | **기술사 또는 기능장** |
| 100억 이상 | 고급기술자 이상 | **기술사·기능장 또는 특급기술인** |
| 30억 이상 | 중급기술자 이상 | **고급기술인 이상** |
| 30억 미만 | 초급기술자 이상 | **중급기술인 이상** |

원문은 구간마다 단일 등급을 지정하지 않고 자격·경력 조합을 열거한다.
예를 들어 30억원 이상 구간의 원칙은 고급기술인 이상이고, 중급기술인은
동종현장 시공관리 3년 이상인 경우에 한해 인정된다.

**이 값은 발주처에 제출하는 검토·확인서에 그대로 들어간다.**
이미 발행된 검토서가 있다면 해당 항목을 다시 확인할 것.
정확한 표는 `tools-site/src/tools/engineer-grade.mjs` 의 `TIERS` 에 정리해 두었다.

**같이 처리할 것 (보안)**: 현재 `data.json` 스키마 예시에 실제 협력사의 상호·대표자·
법인등록번호·계약금액이 들어 있다. 스킬을 외부에 전달하기 전에 반드시 가상 값으로 교체한다.

## 3. 문서관리대장 누락 대조 — 이식 공수 2일

**현장 종속 값**:

| 항목 | 현재 | 프로파일 키 |
|---|---|---|
| 문서번호 현장 코드 | `HG` 고정 | `project.siteCode` |
| 문서번호 토큰 순서 | 파서에 고정 | `documentNumber.pattern` |
| 관리대장 헤더/데이터 행 | 3행 / 4행 고정 | `ledger.headerRow` / `.dataStartRow` |
| 제목 열 위치 | TFA=H, TFR=G 고정 | `ledger.columns.제목` |
| 정리본 제목 병합셀 | 공사명 하드코딩 | `ledger.titleLine1` / `.titleLine2` |

**대조 로직은 범용이다.** 제목 정규화 후 exact match → `difflib` 유사도 비교 →
0.9 이상은 사용자 확인이라는 절차는 현장과 무관하게 유효하다.
특히 "문서번호가 아니라 **제목** 기준으로 대조해야 한다"는 규칙은
협력사가 공종·번호를 제각각 매핑하는 현실에서 나온 것이라 어느 현장에서나 같은 문제가 있다.

**주의**: 문서번호 체계는 현장마다 토큰 순서가 다르다. `{sender}-{siteCode}-{type}-{trade}-{serial}`
패턴을 프로파일에서 받아 파싱하도록 바꿔야 하며, 온보딩 때 실제 문서번호 20건으로 검증한다.

---

## 4. 주간 회의안내 메일 — 이식 공수 1일

**현장 종속 값**: 수신자 목록, 회의 요일·시각, 메일 본문 문구.

한국 공휴일이면 화요일로 대체하고 월·화 모두 공휴일이면 발송하지 않는다는 규칙은 범용이다.
Outlook + Windows 작업 스케줄러 구성이라 **고객사 PC 안에서 돈다** — 자료 반출이 없다.
단독 판매보다는 정액제에 묶어 "덤"으로 넣는 편이 낫다. 체감은 크고 원가는 낮다.

---

## 5. 휴일작업계획서 취합 — 이식 공수 5일 이상, 별도 견적

**여기가 유일하게 어려운 곳이다.** 앞의 넷과 성격이 다르다.

| 항목 | 왜 어려운가 |
|---|---|
| 협력사 고정 목록 | 당직자 열 순서가 곧 출력 서식. 현장마다 업체 구성이 다름 |
| 시트명 `PM단 보고용` | 현장·업체마다 다름 |
| 열 너비·글꼴(굴림체) | 현장 서식 그대로 재현해야 결재가 통과됨 |
| `finalize()` 호출 순서 | LibreOffice가 병합범위 열 너비를 리셋하는 버그를 우회하는 순서 의존 코드 |

앞의 넷은 **입력을 읽어 산출물을 만드는** 일이라 규칙이 명확하지만,
이건 **남의 엑셀 서식을 픽셀 단위로 재현하는** 일이다. 서식이 바뀌면 코드가 바뀐다.

> **판매 방침: 정액제 기본 항목에 넣지 않는다.** 현장 서식을 실제로 받아 본 뒤
> 별도 견적한다. 넣고 나서 "생각보다 다르다"가 되면 정액제 수익이 통째로 날아간다.

---

## 온보딩 시 반드시 받아야 할 것

새 현장에 설치할 때 아래를 먼저 받는다. 없으면 견적을 내지 않는다.

- [ ] 정식 공사명, 원사업자 상호·대표자, 원도급 공사기간
- [ ] 건설사업관리기술자 성명 (검토서 서명란)
- [ ] 실제 문서번호 **20건 이상** (파싱 검증용 — 예시 1~2건으로는 반드시 빠뜨린다)
- [ ] 문서관리대장 실물 1부 (컬럼 위치 확인용)
- [ ] 완성된 산출물 견본 각 1부 — **가장 중요하다.** "이렇게 나와야 한다"의 기준
- [ ] 휴일작업계획서를 포함할 경우: 협력사별 개별 장표 전부 + 취합본 견본

## 견적 산식

기본 4종(회의록·하도급검토서·문서대장·주간메일) = 5.5일 ≈ **초기 세팅 300만원**
휴일작업계획서 포함 = 10.5일 이상 ≈ **초기 세팅 500만원 이상**

공수에는 서식 재현 검증(PDF 변환 후 육안 확인)이 포함된다.
표가 깨진 채 납품되면 그 현장은 다시 안 쓴다.
