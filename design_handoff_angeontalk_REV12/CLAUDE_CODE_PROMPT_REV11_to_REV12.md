## 👇 여기서부터 Claude Code에 붙여넣기

안건톡(건설 현장 업무 메신저) 기존 구현(REV11)에 REV12 변경분을 추가해줘.
REV12는 **채팅방 생성 기능과 초대 기능**을 새로 추가하는 작업이다. 지금까지는 건축방·토목방 같은 공종방이 이미 존재한다는 전제로 화면을 만들어왔는데, REV12를 계기로 모든 채팅방은 특별한 시스템 생성 없이 사용자가 직접 만드는 동일한 종류의 방이라는 걸 반영한다. 즉 공종방과 협력사 단톡방 사이에 기능적 차이는 없고, 이름과 아이콘만 다를 뿐이며, 모든 방에 안건 올리기를 포함한 동일한 기능이 들어간다.
REV12 디자인 레퍼런스: `design_handoff_angeontalk_REV12/anrgeontalk_wireframes_rev12.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 `<style>`에 인라인, 화면 하단 `<script>`에 순수 JS 인터랙션).

기존 다크 테마, Pretendard 폰트, 상태 배지에만 색을 쓰는 원칙, 큰 터치 타깃, 한글 UI를 유지하고, REV11까지 확정된 화면·레이아웃·색상·플로우는 건드리지 말 것. 브랜드 액센트 옐로우 #ffd60a는 CTA·포커스 한정.

이 화면들은 **실제 흐름(화면 전환, 선택, 로컬 상태 변화)까지 구현**하되, 서버 저장이나 실제 데이터 영속화는 이번 범위에 포함하지 않는다.

### REV12 변경 요약

**1. 홈(채팅) 헤더 수정 (레퍼런스 화면1)**
- 검색·설정 아이콘 사이에 방 생성 아이콘(말풍선+플러스) 추가.

**2. 신규 화면 — 채팅방 만들기 (레퍼런스 화면23)**
- 상단 방 아이콘 선택: 원형 기본 플레이스홀더 → 탭 시 건설 현장에 어울리는 아이콘 세트(공구·헬멧·건물·사람들·별 등 12개) 그리드에서 선택.
- 그 아래 방 이름 입력(placeholder "채팅방 이름을 입력하세요").
- 하단 "다음" 버튼 — 이름 비어 있으면 비활성, 입력 시 활성. 누르면 초대 화면(3번)으로 이동.

**3. 신규 화면 — 참여자 초대 (레퍼런스 화면24)**
- 상단에 방금 설정한 방 이름·아이콘 요약.
- "빠른 선택" 섹션: 현재 현장에 등록된 업체를 가로 스크롤 칩으로 나열(동부건설·삼우이엔지·한양기공·세진소방 등 목업 3~5개). 칩 탭 → 해당 업체 소속 전원이 아래 목록에서 한 번에 선택(칩도 강조 표시).
- 구분선 아래 기존 연락처 탭(REV3~7)과 동일한 스타일의 공종별 그룹 리스트 + 개별 체크박스. 빠른 선택으로 선택된 사람은 체크박스 자동 체크.
- 상단 검색 필드로 이름 검색 가능.
- 하단 "N명 초대하고 방 만들기" 버튼 — 선택 인원수 실시간 반영, 최소 1명 이상 선택해야 활성.

**4. 방 생성 완료 후 홈 화면 반영**
- "초대하고 방 만들기" 클릭 → 짧은 완료 피드백 후 홈(채팅 탭)으로 복귀, 새 방이 목록 최상단(또는 최근 활동 순서)에 추가된 상태로 표시.

**5. 신규 — 기존 방에 참여자 추가 초대 (레퍼런스 화면1-1 롱프레스 메뉴에 항목 추가)**
- 공종방/일반방 헤더 더보기 메뉴 또는 채팅방 정보 설정 화면에 "참여자 초대" 항목 추가.
- 탭하면 3번과 동일한 구조의 초대 화면이 뜨되 타이틀만 "참여자 초대"로 바뀜. 이미 참여 중인 사람은 목록에서 **회색 처리 + 선택 불가**(중복 선택 방지).
- 참여 권한은 방에 속한 모든 사람에게 있으므로 별도 관리자 전용 표시는 하지 않음.

### 구현 지침
- REV11 코드 구조/컴포넌트 패턴/상태관리/디자인 토큰 소스를 그대로 따라 신규 화면·상태 추가.
- 초대 화면(3번, 5번)은 **기존 연락처 탭 컴포넌트를 최대한 재사용**해서 체크박스 선택 기능만 얹는 방식으로 구현.
- 변경 후 REV11 화면 회귀 없는지 확인.
