## 2. 본인만 할 수 있는 것 — 우선순위 순

### ① 저장소를 private 으로 (지금, 1분)

**초기 커밋에 실제 프로젝트의 지상 1~3층 평면도가 들어 있다.**
치수·그리드·대지경계선이 그대로 담긴 원 도면이고, 저장소는 현재 **public** 이다.

워킹트리에서는 가상 도면으로 교체했지만 **git 히스토리에는 그대로 남아 있다**
(커밋 `d25a72f`). 파일을 지우는 것만으로는 해결되지 않는다.

1. 저장소를 private 으로 전환 — 노출 확대를 먼저 멈춘다
2. `git filter-repo` 로 히스토리에서 제거 후 force-push
3. 회사 보안 담당·발주처 보고 여부 판단

### ② 하도급검토서 스킬의 배치기준 수정 (오늘)

스킬의 11번 자동 산정 표가 별표5 원문과 다르다. **전 구간이 한 등급씩 낮다.**

| 공사예정금액 | 스킬의 값 | 별표5 원문 |
|---|---|---|
| 500억 이상 | 특급기술자 이상 | **기술사 또는 기능장** |
| 300억 이상 | 특급기술자 이상 | **기술사 또는 기능장** |
| 100억 이상 | 고급기술자 이상 | **기술사·기능장 또는 특급기술인** |
| 30억 이상 | 중급기술자 이상 | **고급기술인 이상** |
| 30억 미만 | 초급기술자 이상 | **중급기술인 이상** |

**이 값은 발주처에 제출하는 검토·확인서에 들어간다.**
이미 발행한 검토서가 있으면 해당 항목을 다시 확인할 것.
정확한 표는 `tools-site/src/tools/engineer-grade.mjs` 의 `TIERS` 에 있다.

같은 스킬의 `data.json` 예시에 실제 협력사 상호·법인등록번호·계약금액이
들어 있는 것도 함께 정리한다.

### ③ 계산기 사이트 배포 (30분)

이걸 하지 않으면 지금까지 만든 것이 전부 잠잔다.

1. Vercel 에 저장소 연결, **Root Directory 를 `tools-site` 로 지정**
   (루트에 Next.js 앱이 있어 지정하지 않으면 그쪽을 빌드한다)
2. 도메인 연결 — 광고를 붙이려면 자기 도메인이 필요하다
3. `tools-site/src/shell.mjs` 의 `SITE.origin` 을 실제 주소로 변경
4. **Google Search Console 등록 + sitemap.xml 제출** — 이걸 해야 검색에 잡힌다

### ④ 취업규칙·근로계약서 확인

직무발명 귀속과 겸업 제한. 겸업은 감수하겠다고 하셨으나,
**재직 중 만든 산출물의 소유권**은 별개 문제다. 나중에 터지면 전부 날아간다.

## 3. 다음에 이어서 할 일

우선순위대로. 하나씩만 해도 된다.

1. **계산기를 20종까지** — 한 주에 하나면 반년. `tools-site/README.md` 에 후보 목록.
   추가할 때마다 `node verify.mjs` 를 돌린다.
2. **애드센스 신청** — 도구가 쌓이고 검색 유입이 생긴 뒤에 신청한다.
   `SITE.adsensePublisherId` 에 넣으면 전 페이지에 자동 적용.
3. **조합 회의록으로 첫 외부 고객** — 근거가 가장 세고(도시정비법 제125조,
   위반 시 조합임원 처벌) 녹음이 법으로 요구되어 입력이 이미 존재한다.
   회의록 스킬은 이식 공수가 사실상 0이다.
4. **제안 페이지에 담당·연락처 기입** 후 발송.

## 4. 이 세션에서 잡은 오류

작업 중 실제로 발견해 고친 것들. 같은 종류가 또 나올 수 있으니 남긴다.

| 무엇 | 어떻게 드러났나 |
|---|---|
| 실제 설계도면이 public 저장소에 | 데모 데이터 점검 중 |
| 배치기준 표 전 구간 오류 | 공개 전 법령 원문 대조 |
| 부가세 역산 1원 오차 (부동소수점) | `verify.mjs` 계산 검증 |
| 한글 금액 "일만" (→"만") | `verify.mjs` 계산 검증 |
| 회의록 마지막 결론이 빈 문단으로 교체 | 생성 후 XML 검사 |
| 카드뉴스 `✕`·`金`·`整` 글리프 깨짐 | 렌더 전 글꼴 검사 |

**공통점: 눈으로 봐서는 안 걸렸을 것들이다.**
검증 스크립트를 만들어 돌린 데서 나왔다. 도구를 늘릴 때도 같은 방식으로 간다.

## 5. 확인이 필요한 것

- 계산기의 법령 근거는 작성 시점 기준이다. **조문은 개정된다.**
  영업 자료나 문서에 인용하기 전 국가법령정보센터에서 시행일 기준 현행 조문을 확인할 것.
- 회의록 DOCX 는 이 환경의 LibreOffice 고장으로 **PDF 육안 검증을 못 했다.**
  고객에게 보내기 전 정상 환경에서 한 번 열어볼 것.
- `doc-automation/PORTABILITY.md` 의 "조문 미확인" 표시된 직종 후보들은
  진입 전 근거를 확인해야 한다.
