## 기능
기둥·보·RC벽으로 3D 골조 해석 모델을 만들어 고정·활·풍·지진하중(KDS)으로 해석하고 부재 검토비·층간변위를 확인합니다.

## 데이터
- 읽기: P.content(els), P.levels, P.base, P.site
- 쓰기: P.struct, P.issues(검토 결과 이슈 등록)
- 다른 트랙에 제공하는 함수: -

### 입력 원칙 (v14)
- 사용자 입력: 건물 용도, 지역(기본풍속·지진구역, 해외는 직접 입력), 지반분류(미조사 시 S4), 허용지내력(미입력 시 필요 지내력만 산정), 노풍도
- 툴이 자동 산정하고 근거를 표시: 내진등급, 구조시스템·R, 지진 해석법, P-Δ, 마감하중, 풍하중 계수, 콘크리트 강도(부재·층 구간별), 철근 등급, 강재 등급, 주근비
- KDS 고정값: 하중계수, 강도감소계수, 균열강성계수
- 툴 자동 산정(v16·v17): 횡지지 길이 Lb·Cb, 유효길이계수 k(ψ), 횡이동 여부(Q), 접합부 볼트·연결판·용접·스티프너
- 원칙: 콘크리트 강도·철근 규격처럼 보편적인 설계값은 사용자가 지정하지 않고, 툴이 안전계수를 고려해 계산·제안한다. 사용자는 현장 특수 수치와 용도만 입력한다.

### 구현 현황
- 해석: 3D 골조 선형정적, 티모셴코 보, 층 강막, RC 벽(벽기둥+강체연결), 고유치+응답스펙트럼(CQC, 85% 보정), P-Δ, 보 단부 핀
- 설계(KDS 14): RC 보·기둥(2축 P-M)·벽, 철골(H1-1), SRC, 실배근·자동배근, 처짐, 독립·매트 기초, 슬래브(MITC4, Branson, Wood–Armer)
- 철골 휨(v16): 횡비틀림좌굴(Lp·Lr, 비탄성·탄성) + 플랜지 국부좌굴. Lb·Cb 자동 — 슬래브가 상부 플랜지를 구속하면 부모멘트 구간(변곡점까지)만, 없으면 골조 절점 사이. 캔틸레버 Cb=1
- 철골 접합부(v17): 철골 보 양단의 지지 부재(철골·SRC 기둥 강축/약축, 큰보, RC 벽·보)와 단부 조건으로 형식 결정. 전단판(F10T 마찰접합, 1·2열, 탄성법 편심)·필릿 용접 자동 설계, 강접은 플랜지 CJP + 기둥 플랜지휨·웨브항복·크리플링 → 수평 스티프너, 패널존 → 웨브 보강판, 큰보는 볼트 연결판, RC는 매입 철판·스터드(콘크리트 파괴 별도)
- 세장효과(v16): 층 안정지수 Q로 횡이동 판정(0.05), 접합 보·기둥 강성비 ψ로 k 산정, RC δns(M2,min·Cm·βdns)·δs, 철골 B1·B2. P-Δ 해석 시 δs=1. 확대 모멘트로 P-M·H1-1 검토 및 재료 자동 산정
- 시뮬레이션: 풍향·풍속 변형, 지진 시간이력(모드 중첩), 장기처짐, 기둥 축소량(ACI 209)
- 구조형식 비교·추천(v15): RC 라멘·벽식·무량판, 철골+데크, 철골+코어, SRC+데크, PC 7개 형식을 같은 평면에서 자동 생성·해석·설계 → 물량·공사비·공기·점수로 비교, 용도별 가중치로 추천, 적용/되돌리기
- 샘플 검증: RC 근생(의도된 NG 2), 2층 주택(전 부재 적합), 50층 타워(응답스펙트럼+P-Δ, 전 부재 적합)
