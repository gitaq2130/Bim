## 기능
측점으로 지형(TIN·등고선·경사)을 만들고, 대지를 계획고로 정지할 때의 절·성토량, 건물 터파기, 잔토 운반, 우수 유출량과 우수관 관경을 산정합니다. 레퍼런스: Civil 3D 지형·정지·토공 워크플로.

## 데이터
- 읽기: P.content(SITE 레이어 대지경계, 슬래브 외곽, 포장 furn), P.landscape.last.green
- 쓰기: P.civil
- 공용 모듈: `js/sitegeo.js`(core)
- 다른 트랙에 제공하는 함수: `civilCalc(P)`

### 설계 원칙
- 사용자 입력: 측점(현장 측량), 강우강도(지역 강우강도식), 계획고를 직접 정할 때만 계획고
- 툴 자동 산정: 절·성토 균형고(토량환산 C=0.9, L=1.25), 1층 FL 권장, 유출계수(지붕 0.9·포장 0.85·녹지 0.25), 우수관 관경(Manning n=0.013, 구배 1%), 빗물관리시설 용량
