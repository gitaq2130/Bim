| 항목 | 값 |

| 소유 파일 | `app/tools/landscape.js` |

## 기능
대지 안 녹지를 산정해 법정 조경면적과 식재 기준을 검토하고, 자동 식재 계획과 수목 일람표(물량·공사비·탄소흡수·관수)를 만들어 모델에 반영합니다. 레퍼런스: Vectorworks Landmark, Land F/X 식재 계획.

## 데이터
- 읽기: P.content(대지경계, 슬래브, 포장 furn)
- 쓰기: P.landscape, L 공종 시트(`landscape:true`)의 furn tree·shrub
- 공용 모듈: `js/sitegeo.js`(core)
- 다른 트랙에 제공하는 함수: `SPECIES`, `landCalc`, `autoPlant`, `applyToModel`, `legalRatio`

### 설계 원칙
- 사용자 입력: 녹지·옥상녹지를 직접 그릴 때만 영역, 수종 교체
- 툴 자동 산정: 법정 조경비율(연면적 기준), 교목 0.2주/㎡·관목 1.0주/㎡, 상록 20%·향토 10% 보정, 배치(건물 2 m·경계 1 m 이격, 좁은 대지는 단계 완화)
