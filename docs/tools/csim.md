## 기능
프리콘 완료 모델과 도급내역으로 착공~준공을 하루 단위로 시뮬레이션합니다. 3D에서 날짜를 움직이거나 재생하면 그날의 부재 상태(철근·매립·거푸집·타설·양생·탈형·외장·방수·완료)와 가설(비계/보호망·동바리·거푸집·타워크레인·호이스트·펌프카·흙막이·가설울타리), 공종별 인원·장비가 보입니다.

### 작업 생성 규칙
- 존: 층 슬래브 면적 420㎡당 1존(최대 4), 긴 방향으로 분할. 여러 존에 걸친 슬래브는 존마다 1/Z 수량.
- 골조 사이클(층 i): 먹매김 → (철골 세우기) → 기둥·벽 철근 → 매립(전선관·박스·접지선·슬리브, 철근 마지막 날 병행) → 기둥·벽 거푸집 → 동바리·보/슬래브 거푸집(또는 철골 보 → 데크·스터드) → 보 철근 → 슬래브 하부근 → 슬래브 매립 → 상부근·검측 → 타설 → 양생(달력일) → 측면 탈형. 동바리 해체는 타설 14일 후 + 상부 2개층 타설 후.
- 옥상: 파라펫 철근 + 피뢰 파라펫링 결속 → 인하도선 확인 → 거푸집 → 타설 → 양생 → 탈형 → 바탕정리 → 방수 → 담수 48h → 보호층 → 후레싱·두겁석.
- 외장(층별, 비계 설치 후): 조적·외단열 / 창호 프레임 → 유리·실링 / 커튼월 / 핀 / 외벽 마감. 15층 초과는 비계 대신 보호망(SCN) 인상.
- 실내(층별, 동바리 해체 후): 조적·경량벽 1면 → 덕트·배관·트레이·샤프트·스프링클러 → 벽체 내 입선·분전반 → 천장 속 검측 → 경량벽 2면 → 천장 틀 → 천장 보드 → 벽 마감 → 바닥 → 걸레받이 → 조명·헤드·결선 → 문 → 가구·위생 → 청소.
- 공정률: 작업 물량 × 도급내역 단가(기성 금액) 누계 ÷ 총액. 금액이 없으면 인·일 가중.
- 기간: 내역 코드별 생산성(PROD)으로 목표 기간 안에 끝내도록 조 편성(상한 있음).
- 도급내역: 코드 → 작업, 이름 키워드 → 작업, 그래도 없으면 '내역 항목' 작업으로 준공 전 삽입(위치 지정 필요 표시). 모델 물량이 없는 표준 코드는 제외.

### 재계획
- 실적 `actual[taskId] = {s, f, pct}` 고정, 데이터 기준일 이후로 나머지 계산.
- 역순 시공(후행 착수 & 선행 미완료) → "보완: 선행 완료 후 후행 부분 해체·복구·재검측" 작업(후행 기간의 30%) 삽입, 후행의 후속 작업이 보완 작업을 기다림.
- 지연 상황: 우천(외부 작업 중지), 협력사(공종 중지), 자재(내역 코드 중지), 전체 중지.
- 기준 공정 대비 지연, 영향받는 작업, 만회 대안(주 6일·주공정 인원 1.5배·존 추가).
