## 기능
실(방)을 정의하고 용도를 고르면 목표 조도가 정해지고, 조명기구 배치로 평균 조도를 계산합니다 (광속법). 슬래브에서 실 만들기, 목표 조도 기준 조명 자동 배치를 제공합니다. 마감표 탭에서 용도별 표준 마감(바닥·걸레받이·벽·천장)과 실별 수정값으로 마감 물량을 산정하고, 천장고를 구조·설비 높이에서 자동 산정해 실 → 천장 객체를 만듭니다. 가구 카탈로그와 가구 3D 형상도 이 트랙 소유입니다.

## 데이터
- 읽기: P.content(slab 등), P.levels
- 읽기(천장고 산정): 상부 층 slab.t, 같은 층 beam.d, duct·pipe·tray의 z·hh
- 쓰기: P.interior, 인테리어 객체(room·ceiling·light·furn)
- `P.interior.finishes.rooms[실 id] = { floor?, base?, wall?, ceil?, h? }` — 용도 표준과 다른 값만 저장 (h = 천장고 직접 지정)
- 자동 생성 천장: `ceiling.room = 실 id` (연결 표시, 재실행 시 갱신·노출이면 삭제). 자동 배치 조명(`light.auto`)은 천장고를 따라감
- 다른 트랙에 제공하는 함수: `tools/interior.js`(roomLighting·LUX_BY_USE) ·`roomFinishes`·`FIN_BY_USE` → (cost, 코어 요청 대기), `js/furn.js` → core·cad·ifcout, `tools/furn3d.js` → view3d

### 설계 원칙
- 사용자는 실 용도만 고르고, 목표 조도(KS A 3011 대표값)와 기구 수·배치는 툴이 산정한다.
- 천장고 = min(용도 권장, 구조체 하단 − 150, 설비 하단 − 100) − 천장재 두께, 50mm 내림. 거실류는 반자높이 2.1m 이상 점검 (건축물의 피난·방화구조 등의 기준에 관한 규칙 제16조). 사용자는 필요 시 직접 지정만 한다.
- 마감 물량: 바닥·천장 = 실 면적, 걸레받이 = 둘레 − 문 폭, 벽 = 둘레 × 천장고(노출천장은 구조체 하단) − 실 경계 위 개구부.
- 조명기구는 interior가 배치하고, 전기 부하·회로는 mep가 light 객체의 watt를 읽어 계산한다.
