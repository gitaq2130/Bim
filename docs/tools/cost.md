## 기능
객체에서 콘크리트·거푸집·철근·철골·마감 물량을 자동 산출하고 내역 단가를 연결합니다. 회차별 진척률을 입력하고 협력사 청구량과 모델 물량을 대비해 기성을 검토합니다.
