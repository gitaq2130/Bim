## 👇 여기서부터 Claude Code에 붙여넣기

안건톡(건설 현장 업무 메신저)의 기존 구현(REV1)을 REV2로 업데이트해줘.
REV2 디자인 레퍼런스: `design_handoff_angeontalk_REV2/anrgeontalk_wireframes_rev2.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 상단 `<style>`에 인라인, 각 화면은 `<!-- SCREEN n -->` 주석으로 구획).

기존 다크 테마, Pretendard 폰트, "상태 배지에만 색을 쓰는" 원칙, 큰 터치 타깃(장갑 착용 대응), 한글 UI를 **그대로 유지**하고, 아래 변경분만 반영해줘. REV1에서 확정된 화면(홈/공종방/안건 올리기/안건방/안건 리스트/보고서 시트/기술사례/완료 처리/사전검토/6개월 추적 등)의 레이아웃·색상·플로우는 건드리지 말 것.

### REV2 변경 요약 (이 부분만 구현)

**1. 하단 탭바를 2개 → 3개로 확장**
- REV1: 채팅 / 마이페이지
- REV2: **연락처 / 채팅 / 마이페이지** (이 순서, 연락처가 맨 왼쪽)
- "연락처" 아이콘은 person/contact 형태(레퍼런스는 lucide `contact-round`).
- 홈(채팅 목록) 화면의 탭바도 이 3개 구성으로 교체. 각 화면에서 현재 위치한 탭만 active.

**2. 신규: 연락처 탭 — 보유 연락처 목록 화면** (레퍼런스 SCREEN 14)
핵심 원칙(문구·동작에 반드시 반영):
> **연락처 정보는 본인이 직접 등록한 것만 존재한다.** 다른 사람이 임의로 누군가의 명함/연락처를 대신 입력할 수 없다. 각자 자신의 명함을 스스로 채우면 그 정보가 상대방의 연락처 목록에 자동 노출된다. "등록"이라는 단어는 **항상 주체가 본인**임이 드러나야 한다. ("명함을 등록해 보세요" O / "연락처를 추가하세요" X)

- 상단 앱바: "연락처" 타이틀 + 우측 검색 아이콘만. **연락처를 직접 추가하는 [+] 버튼은 절대 넣지 말 것** (등록은 본인 프로필에서만 발생).
- 상단 "내 프로필" 섹션: 본인 아바타 + 이름 + 안내 문구 "명함을 등록하면 함께 일하는 사람들에게 자동으로 보여요". 탭하면 본인 편집 모드(아래 3-B)로 이동. **명함 미등록 상태면** 아바타 자리에 점선 원 + "명함 등록하기" CTA.
- 구분선 아래 "공종별 담당자" 섹션: 함께 일한 적 있는(안건방·공종방에서 접점이 있었던) 사람만 자동으로 목록에 노출. 공종 태그별 그룹핑(예: 🔨 건축 / 🔧 설비), 그룹 접기/펼치기 가능.
- 각 연락처 항목: 원형 아바타 + 이름 + 직급/소속(흐린 톤) + 소속 회사 배지.
  - **명함 등록한 사람**: 정상 표시, 탭 → 타인 조회 프로필(3-A).
  - **명함 미등록한 사람**: 아바타 흐리게(비활성 톤) + 이름 옆 "명함 미등록" 라벨. 탭해도 상세 없이 "아직 명함을 등록하지 않았어요" 안내만. 단 채팅 버튼은 가능.
- 하단 카운터: "전체 연락처 N명 · 명함 등록 M명" (등록률을 은근히 노출).
- 정렬 토글: 최근 대화순 / 가나다순.

**3. 신규: 프로필 상세 화면 (3가지 상태)**

공통 레이아웃: 상단 뒤로가기 + 더보기(⋮) / 프로필 헤더(이름 + 직급 + 소속회사 + 우측 원형 아바타) / 원형 액션 버튼 4개(전화 / 채팅 / 이메일 / 함께한 안건 보기) / 탭 3개(명함 정보 · 메모 · 활동 이력).
명함 정보 탭 = 본인이 등록한 명함 이미지 카드(회사/영문명/국문명/직급/주소/전화·팩스·이메일) + 하단 "정보" 섹션(휴대전화·이메일·유선전화·소속 현장·담당 공종; 라벨 흐린 톤, 값 밝은 톤, 전화·이메일은 링크색).

- **3-A. 타인 프로필 조회 (읽기 전용)** — 레퍼런스 SCREEN 15 / 15-1
  - "편집" 버튼 없음. 모두 읽기 전용.
  - 상단에 작은 안내 한 줄: "본인이 등록한 정보입니다" (출처가 본인 자율 등록임을 알림).
  - 전화/채팅 = 강조 CTA, 이메일 = 보조 톤.
  - 활동 이력 탭: "이 사람과 함께한 안건 N건" — **안건톡 데이터 기반**이므로 본인 등록 명함 정보와 **시각적으로 구분되는 섹션**(파란 톤 박스)으로 배치. 안내: 활동 이력은 앱 데이터 기반이며 상대가 공개를 허용한 경우에만 표시.

- **3-B. 본인 프로필 편집 — 명함 미등록 최초 진입** — 레퍼런스 SCREEN 16
  - 전체 점선 빈 상태 + "명함을 등록하면 함께 일하는 동료들이 자동으로 확인할 수 있어요" + 중앙 큰 버튼 "명함 등록하기".

- **3-C. 본인 프로필 편집 모드** — 레퍼런스 SCREEN 17
  - 우측 상단 "편집" 버튼(옐로우 강조).
  - 명함 이미지(촬영/업로드), 이름/직급/소속, 연락처 필드가 인라인 입력 형태.
  - **안건톡 활동 정보(참여 안건 수·검증 사례 수) 공개 여부 토글 스위치** 포함. **기본값은 비공개(꺼짐).** 즉 명함 정보는 등록하면 자동 공개되지만, 안건톡 활동 데이터는 본인이 별도로 공개를 허용해야 상대에게 보인다. 안내 문구로 이 차이를 명시.
  - 하단 "저장" 큰 버튼.

### 데이터 / 상태 모델 (REV2 추가분)
- `me`: {name, rank, company, bizCardRegistered(bool), bizCard{nameEn, address, phone, fax, email, mobile}, site, trade, activityPublic(bool, default false)}
- `contact`: {id, name, rank, trade, company, bizCardRegistered(bool), lastTalkedAt} — **본인이 직접 등록한 경우에만 bizCard 데이터 존재**. 타인이 대신 생성 불가.
- 연락처 목록은 "함께한 안건/공종방 접점"에서 자동 파생. 수동 추가 엔드포인트/버튼 없음.
- 타인 프로필의 활동 이력은 `contact.activityPublic === true`일 때만 응답에 포함.

### 구현 지침
- REV1 코드 구조/컴포넌트 패턴을 따라 신규 화면을 추가할 것 (동일 프레임워크, 동일 상태관리, 동일 디자인 토큰 소스).
- 탭 네비게이터에 "연락처"를 첫 번째 라우트로 추가하고, 연락처 → 프로필 상세(타인 조회 / 본인 편집) 라우팅 연결.
- 사진/명함/도면은 플레이스홀더 → 실제 이미지 업로드·뷰어로 대체.
- 변경 후, 기존 화면 회귀 없는지 홈 탭바만 3개로 바뀌고 나머지는 그대로인지 확인.
