## 👇 여기서부터 Claude Code에 붙여넣기

안건톡(건설 현장 업무 메신저) 기존 구현(REV7)에 REV8 변경분을 추가해줘.
REV8은 여러 현장을 아우르는 신규 **"현장" 탭**을 추가하는 작업이다. 지금까지의 화면들은 암묵적으로 하나의 현장을 가정하고 만들어졌는데, REV8에서 처음으로 여러 현장을 조회하는 최상위 레이어가 생긴다.
REV8 디자인 레퍼런스: `design_handoff_angeontalk_REV8/anrgeontalk_wireframes_rev8.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 `<style>`에 인라인, 화면 하단 `<script>`에 순수 JS 인터랙션).

기존 다크 테마, Pretendard 폰트, "상태 배지에만 색을 쓰는" 원칙, 큰 터치 타깃, 한글 UI를 유지하고, REV7까지 확정된 화면·레이아웃·색상·플로우는 건드리지 말 것.

상태색(공통): 검토중 주황 #f59e0b / 조치중 파랑 #3b82f6 / 완료 녹색 #22c55e / 사전검토 보라 #8b5cf6 / 관찰중 하늘 #0ea5e9. 브랜드 액센트(옐로우) #ffd60a는 CTA·포커스 한정.

**REV8은 목업 수준으로 만든다.** 실제 자동 데이터 수집·외부 시스템 연동은 이번 범위에 포함하지 않는다. 전부 수동 입력 기반 화면 흐름만 구현.

### REV8 변경 요약

**1. 하단 탭바 3개 → 4개 확장**
- 기존 순서: 연락처 / 채팅 / 마이페이지 → 변경 후: **연락처 / 현장 / 채팅 / 마이페이지** (현장 탭은 연락처와 채팅 사이).
- 아이콘은 빌딩(또는 지도 핀) 형태. 4개가 되며 각 탭 터치 영역이 좁아지므로 아이콘·라벨 크기를 REV7 대비 살짝 축소해 4개가 균등하게 들어가도록 조정(레퍼런스: 아이콘 26→23px, 라벨 12→11px).

**2. 신규 화면 — 현장 탭 최상위 목록 (레퍼런스 화면19)**
- 하단 탭바 현장 진입점. 상단 앱바에 "현장" 타이틀 + 우측 검색 아이콘.
- 본문: 진행 중인 현장 리스트. 각 항목 = 현장 썸네일 이미지 + 현장명(예: 고창CDC 물류센터 신축공사) + 위치 한 줄 + 진행률/공정 단계 배지 + 오늘 등록된 야적·현황 업데이트 건수 배지.
- 항목 탭 → 해당 현장 상세로 이동.

**3. 신규 화면 — 현장 상세 (레퍼런스 화면20)**
- 상단: 현장명 + 뒤로가기, 현재 날짜 표시 + 날짜 변경 좌우 화살표/캘린더 아이콘.
- 그 아래 도면이 화면 대부분 차지. 도면 위에 야적 구역·작업/장비 구역 표시.
- 도면 하단에 **레이어 온오프 토글 2개**(야적 / 작업·장비) 나란히 — 각각 독립적으로 켜고 끔(둘 다/하나만/둘 다 끔 가능). 켜지면 해당 구역이 도면 위 반투명 색상 영역으로 표시. **야적=주황 계열, 작업·장비=파랑 계열.**
- 우측 하단 플로팅 버튼 "구역 추가하기".

**4. 신규 화면 — 구역 지정 + 정보 입력 (레퍼런스 화면21)**
- "구역 추가하기" 진입. 도면 위에서 드래그로 사각형/다각형 영역 그리기 — 기존 도면 위 위치 핀 찍기(화면3-1) 인터랙션을 **점 하나 대신 영역을 그리는 제스처**로 확장.
- 영역을 다 그리면 하단 바텀시트가 올라오며 입력 폼 표시. 상단에 야적/작업·장비 선택 세그먼트.
  - **야적** 선택 → 자재 종류 / 수량 / 반입일 3개 필드
  - **작업·장비** 선택 → 작업 내용 / 투입 장비 / 작업 인원 3개 필드
- 하단에 큰 저장 버튼.

**5. 신규 — 구역 탭 시 정보 확인 카드 (레퍼런스 화면22)**
- 현장 상세에서 이미 그려진 구역 탭 → 작은 팝업 카드. 구역 종류에 따라 (야적: 자재 종류/수량/반입일, 작업·장비: 작업 내용/투입 장비/작업 인원) 표시. 등록일·등록자도 함께. 카드 하단에 수정·삭제 버튼(작게).

### 데이터 / 상태 모델 (REV8 추가분)
- **Site(현장)** 엔티티 신규: 현장명, 위치, 진행률, 도면 이미지 참조. 기존 안건·연락처가 암묵적으로 한 현장에 속해 있었다면 각 데이터에 소속 현장 필드가 있는지 확인. 없다면 무리하게 소급 연결하지 말고 현장 탭은 새 목업 데이터로 독립 구현해도 됨.
- **Zone(구역)** 엔티티 신규: 소속 현장, 구역 종류(야적/작업장비), 도면 위 좌표 배열, 등록일, 등록자, 종류별 필드(자재 종류·수량·반입일 / 작업 내용·투입 장비·작업 인원). **하나의 Zone은 특정 날짜에 종속된 데이터**로 다룸 — 현장 상세에서 날짜를 바꾸면 그 날짜에 등록된 Zone만 도면에 표시.

### 구현 지침
- REV7 코드 구조/컴포넌트 패턴/상태관리/디자인 토큰 소스를 그대로 따라 신규 화면·상태 추가.
- 도면 위 영역 그리기는 기존 화면3-1(도면 위 위치 핀 찍기) 로직을 최대한 재사용하되 **단일 좌표 대신 좌표 배열**을 다루도록 확장.
- 다중핀 도면뷰(화면18)와 현장 상세 화면은 도면 렌더링 기반 컴포넌트를 공유할 수 있는지 검토하고, 가능하면 **공통 도면 컴포넌트로 추출**.
- 목업 단계이므로 실제 이미지 업로드·좌표 정밀도는 단순 처리 가능, 날짜 변경 시 데이터 전환만 잘 되는지 확인.
- 변경 후 REV7 화면 회귀 없는지 확인.
