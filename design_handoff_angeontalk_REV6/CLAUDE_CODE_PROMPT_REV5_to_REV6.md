REV6 디자인 레퍼런스: `design_handoff_angeontalk_REV6/anrgeontalk_wireframes_rev6.html` (모든 화면이 iPhone 390×844 프레임으로 한 문서에 배치, CSS는 상단·하단 `<style>`에 인라인, 각 화면은 `<!-- SCREEN n -->` 주석으로 구획).

기존 다크 테마, Pretendard 폰트, "상태 배지에만 색을 쓰는" 원칙, 큰 터치 타깃, 한글 UI를 그대로 유지하고, REV5까지 확정된 화면(홈/공종방/안건방/안건 리스트/보고서 시트/기술사례/완료 처리/사전검토/6개월 추적/연락처/프로필 상세/다중핀 도면뷰/타인 프로필 더보기 메뉴/검색 3종)의 레이아웃·색상·플로우는 건드리지 말 것.

상태색(공통): 검토중 주황 #f59e0b / 조치중 파랑 #3b82f6 / 완료 녹색 #22c55e / 사전검토 보라 #8b5cf6 / 관찰중 하늘 #0ea5e9. 브랜드 액센트(옐로우) #ffd60a는 CTA·포커스 한정.

### REV6 변경 요약 (이 4가지만 구현)

---

**1. 신규: 연락처 롱프레스 — 빠른 요약 카드 (레퍼런스 화면 14-1)**

진입점: 연락처 탭(화면14) 리스트 항목을 롱프레스 → 그 항목 아래에 팝업 카드. 배경 딤 처리, 카드는 위로 살짝 뜨는 느낌.

[중요 원칙 1] 이 카드는 빠른 현황 확인용이다. 전화·채팅·이메일 같은 상세 액션은 넣지 않는다 — 그건 이미 이 사람을 탭(숏프레스)했을 때 들어가는 기존 프로필 상세 화면(화면15, 명함 정보 탭)에 있으므로 중복하지 않는다. 롱프레스 카드는 요약과 빠른 상태관리(즐겨찾기/차단)만 담당한다.

[중요 원칙 2] "처리중/처리완료" 숫자는 담당자 기준이다. 즉 이 사람이 담당자로 지정된 안건만 집계한다(단순 참여자로 포함된 안건은 제외).

카드 구성 (위→아래):
1. 이름 + 직급 (큰 글씨, 굵게)
2. 소속회사 · 전문분야 배지 (흐린 톤 + 작은 pill) — 명함 미등록 상태면 "명함 미등록"으로 대체
3. 구분선
4. "담당 안건" 소제목 아래 "처리중 N"(주황) / "처리완료 N"(녹색) — 숫자 강조, 각각 독립적으로 탭 가능(은은한 hover 배경)
5. 구분선
6. ⭐ 즐겨찾기 추가 (이미 즐겨찾기면 "즐겨찾기 해제"로 라벨/아이콘 채움 전환)
7. 🚫 차단하기 (빨간 톤, 맨 아래)

카드 바깥 탭 시 닫힘.

**2. 신규: "처리중 N" 탭 → 담당자 필터 안건 리스트 (레퍼런스 화면 5-1)**

"처리중 N" 탭 시 기존 안건 리스트 화면(화면5)이 재사용되며, 상단에 "김대진 담당 · 진행중" 형태의 필터 태그가 기존 상태 필터 옆에 추가로 붙는다. 리스트는 해당 인물이 **담당자로 지정된** 진행중 안건만 표시. "담당"이라는 단어를 필터 태그에 포함시켜 참여자 필터와 혼동되지 않게 할 것. 하단에 "○○○이 담당자로 지정된 진행중 안건만 표시됩니다" 안내 각주.

---

**3. 신규: 채팅방(공종방) 롱프레스 메뉴 (레퍼런스 화면 1-1)**

진입점: 홈(화면1) 채팅방 목록에서 공종방 항목을 롱프레스 → 컨텍스트 메뉴. 스타일은 기존 메시지 롱프레스 메뉴(.ctxmenu, 화면4-1)와 동일한 다크 서페이스 카드 + 리스트형.

메뉴 상단에 **롱프레스한 채팅방 이름 헤더**(아이콘 + 방 이름)를 표시한다.
메뉴 항목 4개 (세로 리스트, 항목 사이 얇은 구분선):
1. 채팅방 정보 설정
2. 즐겨찾기 추가 (이미 즐겨찾기면 "즐겨찾기 해제")
3. 상단 고정 (이미 고정이면 "상단 고정 해제")
4. 알림 켜기 (알림 꺼진 상태면 "알림 끄기", 아이콘도 벨/벨-슬래시 전환)

메뉴는 채팅방 목록 위에 팝오버로 뜨며 배경 딤 처리. 바깥 탭 시 닫힘. 위험 액션(삭제, 나가기 등)은 포함하지 않는다 — 공종방은 업무 인프라이므로 개인이 임의로 나가거나 삭제할 수 없는 구조임을 반영.

---

**4. 신규: 상단 고정 상태가 반영된 홈 화면 (레퍼런스 화면 1-2)**

- 고정된 채팅방이 리스트 최상단에 별도 구역("고정된 채팅방")으로 분리
- 고정된 방 이름 옆에 작은 핀 아이콘 표시
- 그 아래 일반 채팅방 목록(기존과 동일)이 구분선을 두고 이어짐

---

### 데이터 / 상태 모델 (REV6 추가분)
- `contactSummary`: {inProgressCount, completedCount} — 둘 다 **담당자 기준**으로 집계(assignee == 해당 인물). 참여자(participant) 기준과는 별도 필드이므로 혼동하지 말 것.
- `roomRelation`: {favorite(bool), pinned(bool), muted(bool)} — 채팅방별 개인 설정 플래그.
- 안건 리스트 화면(화면5)에 담당자 필터 파라미터 추가: 기존 상태 필터와 AND 조건으로 결합 가능해야 함(예: 담당자=김대진 AND 상태=진행중).

### 구현 지침
- REV5 코드 구조/컴포넌트 패턴/상태관리/디자인 토큰 소스를 그대로 따라 신규 화면·상태를 추가.
- 연락처 요약 카드와 채팅방 롱프레스 메뉴는 각각 독립적인 팝오버/카드 컴포넌트로 구현하되, 기존 .ctxmenu 스타일 토큰을 재사용.
- **안건 데이터 모델에 `담당자(assignee)`와 `참여자(participants)`가 이미 구분되어 있는지 먼저 확인할 것.** 하나의 배열로 뭉쳐 있다면, 이 REV6 작업 전에 필드를 분리하는 마이그레이션이 선행되어야 "처리중/처리완료" 집계가 정확해진다. 구분이 안 되어 있다면 구현 전에 알려줄 것.
- 변경 후 REV5 화면 회귀 없는지 확인.
